# 한솔아카이브 토스페이먼츠 주문서형 테스트

이 디렉터리를 별도 로컬 HTTP 주소로 열고, 토스페이먼츠 개발자센터에서 발급한 `test_gck_` 클라이언트 키를 사용합니다. 테스트 위젯의 결제 수단과 약관 렌더링을 확인할 수 있습니다. 주문·결제 요청 및 실제 상점 서버와의 연결은 포함하지 않습니다.

다음 통합 단계에서는 테스트 승인 API를 별도 서버에서 호출합니다. 승인 요청 전에 해당 테스트 주문의 주문번호, 금액, 중복 승인 여부를 서버에서 확인하고 `test_gsk_` 키는 서버 환경 변수로만 관리합니다. 정식 적용은 계약 및 심사 상태를 확인한 뒤 별도로 진행합니다.
